# xidian-cs-journey · 西电→嵌入式成长记录

西安电子科技大学本科学习与嵌入式项目作品集。
目标：保研 **北京大学软件与微电子学院 · 电子信息（嵌入式系统设计 / 高端芯片方向）**。

## 背景
- 主修：信息管理与信息系统（经管院，大一上分流）
- 双学位：电子信息工程（2026 首届）
- 方向：嵌入式系统 / 嵌入式 AI / 软硬件协同

## 成长路线
```
C 语言 → 数据结构 → STM32 单片机 → FreeRTOS
      → FPGA/Verilog → 嵌入式 Linux → 嵌入式 AI 端侧部署
```
