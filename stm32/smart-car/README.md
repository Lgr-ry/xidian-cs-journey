# STM32 智能寻迹小车（STM32F103C8T6 · 标准外设库）

课程 / 竞赛实践项目，2026-09 ～ 2026-10 完成基础任务。本目录只放软件实现，不含 ST 标准库与启动文件。

## 硬件

- MCU：STM32F103C8T6（Keil MDK + STM32F10x 标准外设库，无需 CubeMX）
- 执行：双直流电机 + 驱动，PWM 调速，编码器测速
- 传感：8 路灰度（循迹）
- 调试：USART 串口打印运行状态与标定数据

## 软件结构

| 文件 | 职责 |
|---|---|
| `main.c` | 主流程与 `RUN_MODE` 状态机、任务切换 |
| `Hardware/motor.c` | 电机 PWM 与方向控制 |
| `Hardware/encoder.c` | 编码器脉冲读取与速度换算 |
| `Hardware/track.c` | 8 路灰度读取与循迹偏差计算 |
| `Hardware/pid.c` | 增量式 PID（速度环 / 方向环） |
| `Hardware/bsp_time.c` | 定时与延时基准 |
| `Hardware/uart.c` | 串口打印，用于代码调试与阈值标定 |

## 控制思路

1. **双轮速度闭环**：编码器测速 → PID → PWM。两轮物理特性不同会持续跑偏，v2 改为"自动配平"——同一 PWM 跑 0.8 s，用两轮脉冲数之比反推当量，替代手工测量。
2. **循迹**：8 路灰度加权求偏差 → PD 修正方向 → 差速转向。
3. **直角弯**：检测到单侧全黑 / 全白特征后进入状态机分支，原地转向 90°。

## 已跑通（`RUN_MODE` 可切换）

- 双轮定速直行（速度闭环）
- 纯巡线（方向 PD）
- 巡线 + 单个直角弯
- 灰度 8 路标定（只打印，不驱动电机）
- 电机自检（纯前馈）
