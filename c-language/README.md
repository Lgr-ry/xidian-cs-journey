## 错题本（每道错题都要能给别人讲清错因）

1. **E01** scanf 格式串里的普通字符（如逗号）必须在输入时原样敲入。
2. **E02** 占位符与类型必须一一对应：double 用 `%f`，用 `%d` 会打印垃圾值。
3. **E03** `\n` 在 scanf 里表示“继续等非空白字符”，格式串末尾不要写 `\n`。
4. **E04** 同一结果被多个占位符打印时，先把结果存进变量再统一使用。
