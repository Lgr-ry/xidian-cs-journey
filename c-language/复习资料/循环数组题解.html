{
    int n, i, j, a[15], t, sum = 0;
    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%d", &a[i]);
    for (i = 0; i < n - 1; i++)              /* 冒泡升序 */

        sum = sum + a[i];
    printf("%.2f\n", (double)sum / (n - 2));
    return 0;
}

87跳一跳★★★★☆过程模拟 · 连击计数

题目

输入一串跳跃结果（1=跳到方块、2=跳到中心），以 0 结束。跳到方块得 1 分；跳到中心第一次得 2 分，连续第 k 次得 2k 分。输出总分。

思路
  1. 读入直到出现 0，用 while 循环。
  2. 维护两个状态：streak（连续跳中心的次数）、score（总分）。
  3. 读到 1：streak 清零，score 加 1。
  4. 读到 2：streak 加 1，score 加 2*streak（第 1 次 +2，第 2 次 +4…）。
  5. 读到 0：退出循环，输出 score。
main.c
#include <stdio.h>

int main(void)
{
    int x, streak = 0, score = 0;
    while (scanf("%d", &x) == 1 && x != 0)
    {
        if (x == 1)
        {
            streak = 0;              /* 连击中断 */
            score = score + 1;
        }
        else
        {
            streak = streak + 1;     /* 连击加一 */
            score = score + 2 * streak;
        }
    }
    printf("%d\n", score);
    return 0;
}
易错点
  • 连击必须在跳到方块时清零，否则后面的 2 分会一直累加。
  • 结束标记 0 不能计入得分。

样例：1 1 2 1 2 2 2 0 → 17　本地实测：✅ 通过

385报数游戏★★★★★过程模拟 · 三人轮转

题目

三人从 1 开始轮流报数，遇到 7 的倍数或含 7 的数则跳过（不计入已报数）。共报出 n 个数字后结束，输出每人跳过数字的个数。

思路
  1. 外层 while 直到「已报出个数」达到 n。
  2. 每个数先判断是否该跳过：是 7 的倍数，或十进制某位是 7。
  3. 用 skip[3] 记录三人各自跳过次数，用 p 记录轮到谁，p = (p+1)%3。
  4. 跳过的数不计入已报数；没跳过的才让已报数加一。
main.c
#include <stdio.h>

int main(void)
{
    int n, skip[3] = {0, 0, 0};
    int valid = 0, num = 1, p = 0;
    scanf("%d", &n);
    while (valid < n)
    {
        int t = num, has7 = 0;
        while (t > 0)                 /* 判断十进制中是否含 7 */
        {
            if (t % 10 == 7) { has7 = 1; break; }
            t = t / 10;
        }
        if (num % 7 == 0 || has7)
            skip[p]++;                /* 跳过：记在这人名下，不计入 valid */
        else
            valid++;
        p = (p + 1) % 3;              /* 轮到下一个人 */
        num++;
    }
    printf("%d %d %d\n", skip[0], skip[1], skip[2]);
    return 0;
}
易错点
  • 只有「没跳过」的数才让 valid 加一，跳过的数不能算报出。
  • 判断含 7 用 while 拆位，不要用字符串函数。

样例：7 → 1 0 0　本地实测：✅ 通过

384种苹果★★★☆☆过程模拟 · 累计与最大减少

题目

第一行 n 表示疏果轮数；第二行 n+1 个整数，第一个是初始苹果数 t，其后 n 个为 0 或负整数（负数绝对值表示本轮去掉的个数）。输出最终苹果数和疏果最多的轮次（从 1 开始）。

思路
  1. 先读 n 和初始值 cur。
  2. 循环 n 轮：每轮读一个 drop（≤0），cur += drop。
  3. 本轮减少量 = -drop；若大于历史最大，记录最大减少量与轮次。
  4. 循环结束输出 cur 和记录的轮次。
main.c
#include <stdio.h>

int main(void)
{
    int n, t, i, cur, drop;
    int maxdrop = -1, maxround = 1;
    scanf("%d %d", &n, &t);
    cur = t;
    for (i = 1; i <= n; i++)
    {
        scanf("%d", &drop);
        cur = cur + drop;                 /* 累计剩余 */
        if (-drop > maxdrop)              /* 本轮去掉的个数更大 */
        {
            maxdrop = -drop;
            maxround = i;
        }
    }
    printf("%d %d\n", cur, maxround);
    return 0;
}
易错点
  • 最大减少量初值取 -1，这样「全为 0」时也能正确停在第一轮。
  • 轮次从 1 开始计数，用循环变量 i 正好。

样例：2 50 -5 -8 → 37 2　本地实测：✅ 通过

167数字统计排序★★★★☆数组 · 桶计数 + 双层扫描

题目

输入 n 个不超过 1000 的非负整数，统计每个数出现次数，按次数从多到少输出；次数相同的，值小的先输出。每行两个数：值 和 次数。

思路
  1. 开 cnt[1005] 桶，读入时 cnt[x]++。
  2. 不排序：外层枚举次数 c 从 n 递减到 1，内层枚举值 v 从 0 升到 1000。
  3. 外层递减保证次数多的先输出；内层递增保证同次数时值小的先输出。
  4. 只输出 cnt[v] == c 的位置，未出现的值（次数 0）自然被跳过。
main.c
#include <stdio.h>

int main(void)
{
    int n, i, x, c, v;
    int cnt[1005] = {0};
    scanf("%d", &n);
    for (i = 0; i < n; i++)
    {
        scanf("%d", &x);
        cnt[x]++;
    }
    for (c = n; c >= 1; c--)              /* 次数从大到小 */
    {
        for (v = 0; v <= 1000; v++)       /* 值从小到大 */
        {
            if (cnt[v] == c)
                printf("%d %d\n", v, c);
        }
    }
    return 0;
}
易错点
  • 外层上界是 c>=1：写成 c>=0 会把所有未出现的值当次数 0 打印出来。
  • if 里是比较 ==，写成赋值 = 会把所有值都打印一遍。

样例：12 5 2 3 3 1 3 4 2 5 2 3 5 → 3 4 / 2 3 / 5 3 / 1 1 / 4 1　本地实测：✅ 通过

6数字排序★★★★★数组 · 拆位 + 多关键字排序

题目

输入 n 个不超过 10000 的非负整数，计算每个数的各位数字和，按数字和从大到小输出；数字和相同的，值小的先输出。每行两个数：原数 和 数字和。

思路
  1. 需要同时保留「原数」和「数字和」，用两个平行数组 val[]、sco[]。
  2. 读入时立刻算数字和：拆位累加。
  3. 选择排序：每轮在未排好区间找「最该排前面」的下标 k。
  4. 比较规则：sco 更大者优先；sco 相同则 val 更小者优先。
  5. 找到 k 后与位置 i 交换，两个数组必须同步交换。
main.c
#include <stdio.h>

int main(void)
{
    int n, i, j, k, t;
    int val[1005], sco[1005];
    scanf("%d", &n);
    for (i = 0; i < n; i++)
    {
        int x, s = 0;
        scanf("%d", &val[i]);
        x = val[i];
        while (x > 0)                 /* 读入即算数字和 */
        {
            s = s + x % 10;
            x = x / 10;
        }
        sco[i] = s;
    }
    for (i = 0; i < n - 1; i++)       /* 选择排序 */
    {
        k = i;
        for (j = i + 1; j < n; j++)
        {
            if (sco[j] > sco[k] || (sco[j] == sco[k] && val[j] < val[k]))
                k = j;
        }
        if (k != i)                   /* 两个数组同步交换 */
        {
            t = val[i]; val[i] = val[k]; val[k] = t;
            t = sco[i]; sco[i] = sco[k]; sco[k] = t;
        }
    }
    for (i = 0; i < n; i++)
        printf("%d %d\n", val[i], sco[i]);
    return 0;
}
易错点
  • 数字和必须在读入时算并单独存，不能覆盖原数。
  • 两个数组忘了同步交换 = 原数和数字和错位。
  • 冒泡的内层要用 j 比较 a[j] 与 a[j+1]。

样例：5 101 100 999 1234 110 → 999 27 / 1234 10 / 101 2 / 110 2 / 100 1　本地实测：✅ 通过

40等差数列★★★☆☆数组 · 排序后验证

题目

输入 n 个整数，判断能否构成等差数列。不能则输出 no；能则输出公差（相邻两项差的绝对值）。

思路
  1. 题面给的序列是乱序的，先升序排序。
  2. 排序后公差 d = a[1] - a[0]（此时非负，就是绝对值）。
  3. 从 i=1 到 n-1 验证 a[i]-a[i-1] 是否都等于 d（注意上界 n-1，别访问 a[n]）。
  4. 一旦不等，输出 no 并结束。
main.c
#include <stdio.h>

int main(void)
{
    int n, i, j, t, d, a[105];
    scanf("%d", &n);
    for (i = 0; i < n; i++)
        scanf("%d", &a[i]);
    for (i = 0; i < n - 1; i++)               /* 冒泡升序 */
        for (j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j + 1])
            {
                t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
            }
    if (n <= 2)                               /* 一两项总能构成等差 */
    {
        printf("%d\n", n == 2 ? a[1] - a[0] : 0);
        return 0;
    }
    d = a[1] - a[0];
    for (i = 1; i < n; i++)
    {
        if (a[i] - a[i - 1] != d)
        {
            printf("no\n");
            return 0;
        }
    }
    printf("%d\n", d);
    return 0;
}
易错点
  • 验证循环上界是 n（i 从 1 开始，访问 a[i-1]），写成 i<=n 会越界。
  • 成功时输出的是公差 d，不是 yes。
  • no 是小写，与题面一致。

样例：6 23 15 4 18 35 11 → no　本地实测：✅ 通过

54abc 组合★★★☆☆二重/三重循环 · 枚举

题目

已知 abc + cba = n（1000<n<2000），a、c 为 1~9，b 为 0~9。按整数 abc 从小到大的顺序，输出所有满足条件的 a、b、c。

思路
  1. 三重循环枚举 a(1~9)、b(0~9)、c(1~9)。
  2. abc = 100a+10b+c，cba = 100c+10b+a，两者之和 = 101(a+c)+20b。
  3. 按 a、b、c 递增枚举，输出天然就是 abc 从小到大。
  4. 每组输出三个数一行。
main.c
#include <stdio.h>

int main(void)
{
    int n, a, b, c;
    scanf("%d", &n);
    for (a = 1; a <= 9; a++)
        for (b = 0; b <= 9; b++)
            for (c = 1; c <= 9; c++)
                if (101 * (a + c) + 20 * b == n)
                    printf("%d %d %d\n", a, b, c);
    return 0;
}
易错点
  • a 和 c 不能取 0（否则不是三位数），b 可以取 0。
  • 枚举顺序决定输出顺序，a 在最外层才符合「abc 从小到大」。

样例：1352 → 3 7 9 / 4 7 8 / 5 7 7 / 6 7 6 / 7 7 5 / 8 7 4 / 9 7 3　本地实测：✅ 通过

196输出金字塔★★★☆☆二重循环 · 图形

题目

输入一个大写字母，输出字母金字塔，最后一行开头无空格。例如输入 C，输出 A / ABA / ABCBA（逐行居中）。

思路
  1. 行数 rows = 字母 - A + 1。
  2. 第 i 行（i 从 0 起）先打 rows-1-i 个空格。
  3. 再顺序打 A 到 A+i。
  4. 再逆序打 A+i-1 到 A（注意 i=0 时这一轮不执行）。
  5. 每行结束换行，行末不加空格。
main.c
#include <stdio.h>

int main(void)
{
    char mc, ch;
    int rows, i, j;
    scanf(" %c", &mc);
    rows = mc - 'A' + 1;
    for (i = 0; i < rows; i++)
    {
        for (j = 0; j < rows - 1 - i; j++)
            printf(" ");
        for (ch = 'A'; ch <= 'A' + i; ch++)
            printf("%c", ch);
        for (ch = 'A' + i - 1; ch >= 'A'; ch--)
            printf("%c", ch);
        printf("\n");
    }
    return 0;
}
易错点
  • scanf 前加空格（" %c"）可以跳过缓冲区里残留的换行。
  • 第二个字母循环从 A+i-1 开始，i=0 时条件不成立，正好略过。

样例：C → A / ABA / ABCBA　本地实测：✅ 通过

249分解质因数★★★☆☆循环 · 试除分解

题目

输入一个正整数 n（2<n<1000），把它分解成质因数相乘的形式，按从小到大输出，形如 2*3*3*5。

思路
  1. 从 d=2 开始试除。
  2. 只要 n 能被 d 整除，就输出 d、n/=d，并把 d 重复到不能整除为止。
  3. 不能整除时 d++ 继续试。
  4. 用 first 标记控制星号，第一个因子前不输出星号。
main.c
#include <stdio.h>

int main(void)
{
    int n, d = 2, first = 1;
    scanf("%d", &n);
    while (n > 1)
    {
        while (n % d == 0)            /* 同一个因子可能出现多次 */
        {
            if (!first) printf("*");
            printf("%d", d);
            first = 0;
            n = n / d;
        }
        d++;
    }
    printf("\n");
    return 0;
}
易错点
  • 同一个质因子要重复输出（如 90 里的两个 3）。
  • 星号要在因子之间，不能出现在开头或结尾。

样例：90 → 2*3*3*5　本地实测：✅ 通过

50选号程序★★★☆☆循环 · 数位和比较

题目

输入 n 个号码，选出各位数字之和最大的；若多个号码数字和相同，选数值最大的。输出该号码。

思路
  1. 维护 best（当前最优号码）与 bestsco（其数字和）。
  2. 每个号码单独算数字和（拆位）。
  3. 和更大 → 直接替换；和相同且数值更大 → 替换。
  4. 全程只保留一个最优解，不需要数组。
main.c
#include <stdio.h>

int main(void)
{
    int n, i, x, best = 0, bestsco = -1;
    scanf("%d", &n);
    for (i = 0; i < n; i++)
    {
        int t, s = 0;
        scanf("%d", &x);
        t = x;
        while (t > 0)
        {
            s = s + t % 10;
            t = t / 10;
        }
        if (s > bestsco || (s == bestsco && x > best))
        {
            bestsco = s;
            best = x;
        }
    }
    printf("%d\n", best);
    return 0;
}
易错点
  • 并列时要比较数值大小，不能只看数字和。
  • bestsco 初值取 -1，保证第一个号码一定能替换进来。

样例：5 10000 11111 22222 333 1234 → 22222　本地实测：✅ 通过

68日期计算★★★★☆数组 · 查表 + 逐月累减

题目

输入年份 y 和第 d 天，输出这一天是几月几日（考虑闰年）。

思路
  1. 建一张 13 个元素的月份天数表，下标就是月份。
  2. 闰年时把 days[2] 改成 29。
  3. 用 while 逐月减：剩余天数大于当月天数就减去、月份加一。
  4. 循环结束时月份和剩余天数就是答案。
main.c
#include <stdio.h>

int main(void)
{
    int y, d, m = 1;
    int days[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    scanf("%d %d", &y, &d);
    if ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0)
        days[2] = 29;
    while (d > days[m])          /* 用 > 而不是 >=，第 31 天应停在当月 */
    {
        d = d - days[m];
        m = m + 1;
    }
    printf("%d %d\n", m, d);
    return 0;
}
易错点
  • 循环条件用 > ：等于当月天数时应停在当月最后一天，不能进位。
  • 闰年只改 2 月，别改整张表。

样例：2015 80 → 3 21　本地实测：✅ 通过
