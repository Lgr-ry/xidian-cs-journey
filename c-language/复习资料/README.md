## 使用顺序

1. **先做**：模拟卷任选一套，90 分钟限时，不看答案。
2. **再对**：答案卷对思路，只记"我没想出来的那一步"。
3. **补漏**：错的那类去 [通关手册](../c-language/复习资料/循环与数组通关手册.docx) 对应章节，或看 [错题本](../错题本.md) 的错因条目。
4. **考前**：备考卡最后一眼。

## 说明

所有代码均用 gcc 8.1（`-std=c99 -Wall`）编译通过，并跑过题面样例与边界用例。
