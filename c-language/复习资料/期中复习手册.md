## 0. 一张图串起来

```
数据怎么存 ──→ 数据怎么算 ──→ 按条件做选择 ──→ 按次数重复 ──→ 批量处理同类数据
```

## 1. 数据与运算（第 1、2、5 讲）

### 1.1 四种基本类型

| 类型 | 占位 | 范围 / 说明 | 格式符 |
|---|---|---|---|
| `int` | 4 字节 | −2147483648 ~ 2147483647（约 ±21 亿） | `%d` |
| `float` | 4 字节 | 约 6–7 位有效数字 | `%f` |
| `double` | 8 字节 | 约 15–16 位有效数字，**默认用这个** | `%lf`（scanf）/ `%f`（printf 都行） |
| `char` | 1 字节 | 一个字符，存的是 ASCII 码 | `%c` |

必背 ASCII：`'A'=65`、`'a'=97`、`'0'=48`、`'A'` 到 `'Z'` 连续、`'a'` 到 `'z'` 连续、大写与小写差 **32**。

```c
char c = 'a';
c = c - 32;        /* 'a'(97) → 'A'(65) */
```

### 1.2 整数除法（最高频扣分点）

```c
5 / 2      → 2        两个整数相除，结果截断取整
5.0 / 2    → 2.5      有浮点数参与，按浮点算
5 / 2.0    → 2.5
(double)5/2 → 2.5
5 % 2      → 1        取余，只能用于整数
```

**判断口诀**：除号两边**都是整数**才截断。要小数就写 `5.0/9.0` 或加 `(double)`。

### 1.3 类型转换

- **隐式**：低精度 → 高精度自动转换（`int` 与 `double` 混合运算，`int` 转 `double`）。
- **显式**：`(double)a` 、`(int)x`（**截断，不四舍五入**：`(int)3.9 = 3`）。
- `int` 赋给 `double` 安全；`double` 赋给 `int` 丢小数部分。

### 1.4 运算符优先级（从高到低，只需记这个顺序）

```
( )  →  单目 ! ++ -- (类型)  →  算术 * / %  →  算术 + -  →  关系 < <= > >=  →  相等 == !=  →  逻辑 &&  →  逻辑 ||  →  赋值 =
```

**三条实用结论**：
1. 不确定就加括号，**加括号不扣分**。
2. 关系运算符低于算术：`a + 1 > b * 2` 先算两边再比较。
3. 赋值最低：`x = y > 0` 是 `x = (y > 0)`，不是 `(x = y) > 0`。

### 1.5 自增自减

```c
i = 5;
printf("%d", i++);   /* 输出 5，之后 i=6 —— 先用后加 */
printf("%d", ++i);   /* i 先变 7，输出 7 —— 先加后用 */
```

**考试建议**：除非题目专门考这个，**不要在同一个表达式里对同一变量多次自增**（`i++ + i++` 是未定义行为）。

### 1.6 逻辑运算的短路

```c
if (a != 0 && b / a > 1)   /* a==0 时右边不算，不会除零 */
if (x > 0 || y > 0)        /* 左边真，右边不算 */
```
`&&` 左边为假 → 右边不执行；`||` 左边为真 → 右边不执行。**这既是考点，也是保命写法。**

### 1.7 本节易错清单

- [ ] `5/9` 得 0
- [ ] `(int)` 是截断不是四舍五入
- [ ] 变量未初始化（局部变量是垃圾值，不是 0）
- [ ] `=` 与 `==` 混用
- [ ] `3 < x <= 10` 恒真（必须 `x > 3 && x <= 10`）
- [ ] `%` 只能用于整数，`5.5 % 2` 编译错误
- [ ] 字符 `'5'` 与数字 `5` 不是一回事（`'5'` 是 53）

## 2. 输入输出（第 5 讲）

### 2.1 格式符总表（必背）

| 格式 | 含义 |
|---|---|
| `%d` | 十进制整数 |
| `%o` | 八进制整数 |
| `%x` | 十六进制整数 |
| `%f` | 浮点数（默认 6 位小数） |
| `%.2f` | 保留 2 位小数（四舍五入、不足补零） |
| `%e` | 指数形式 |
| `%c` | 单个字符 |
| `%s` | 字符串 |
| `%%` | 输出一个 `%` |

### 2.2 scanf 三条铁律

1. **`&` 的个数 = 变量个数**（字符数组 `%s` 除外：`scanf("%s", s)` 不加 `&`）。
2. **类型必须配对**：`double` 用 `%lf`，`float` 用 `%f`，用错就是垃圾值。
3. **格式串里写什么，输入就敲什么**：`scanf("%d,%d", &a, &b)` 输入要敲 `3,4`；**格式串末尾不要写 `\n`**。

### 2.3 printf 输出格式

```c
printf("%d\n", x);         /* 整数 + 换行 */
printf("%.2f\n", y);       /* 两位小数 */
printf("%5d|", x);         /* 占 5 位右对齐 */
printf("%-5d|", x);        /* 占 5 位左对齐 */
```

**OJ 判题逐字符比对**：多余空格、缺换行、大小写、中文全算错。

## 3. 选择结构（第 6 讲）

### 3.1 三种形态

```c
if (条件) 语句;                        /* 单分支 */
if (条件) 语句1; else 语句2;           /* 双分支 */
if (条件1) ... else if (条件2) ... else ...   /* 多分支 */
```

### 3.2 三个致命细节

1. **`if(...)` 后面不能加分号**：`if (x > 0);` 表示"条件成立时执行空语句"。
2. **花括号能省则省是坏习惯**：分支里有多条语句必须加 `{}`。
3. **`else` 与最近的未配对 `if` 结合**（悬空 else），不确定就加花括号。

### 3.3 switch

```c
switch (表达式) {          /* 表达式必须是整型或字符型 */
    case 1: 语句; break;   /* case 后必须是常量 */
    case 2:
    case 3: 语句; break;   /* 多个 case 共享一段代码 */
    default: 语句;
}
```

**两条规则**：
- **漏 `break` 会向下穿透**（执行完本 case 继续执行下一个 case）。
- **switch 只能做"值分派"，不能做范围判断**。`case (x >= 3)` 是错的——见比较符号就换 `if`。

### 3.4 分段函数的通用写法（累进型）

```c
/* 错误：把"本档全部金额×本档税率"当成增量 */
/* 正确：本档累计 = 上一档累计 + (本档上限 − 上档上限) × 本档税率 */
```

**例**：梯度电价、个税、奖金提成、出租车计价——**同一个模板**。

### 3.5 条件运算符

```c
int max = (a > b) ? a : b;
```
等价于 `if (a>b) max=a; else max=b;`。适合"二选一取值"，不适合写复杂逻辑。

## 4. 循环结构（第 7 讲）

### 4.1 三种循环

```c
while (条件) { 语句; }              /* 先判断后执行，可能 0 次 */
do { 语句; } while (条件);          /* 先执行后判断，至少 1 次 */
for (初值; 条件; 增量) { 语句; }     /* 三要素写在一行，最常用 */
```

### 4.2 循环三要素（必背）

1. **初值**：控制变量从哪开始；
2. **条件**：做到什么程度停；
3. **增量**：每轮怎么变。

**while 循环体内必须有改变条件变量的语句**，否则死循环。

### 4.3 break 与 continue

| 语句 | 作用 |
|---|---|
| `break` | 立刻跳出**本层**循环（或 switch） |
| `continue` | 跳过本次剩余语句，进入下一轮 |

### 4.4 循环边界三问（写完循环必答）

1. 循环执行**几次**？
2. **最后一次**循环时，控制变量是多少？
3. 循环结束时，控制变量是**多少**？

> 例：`for (i = 0; i < n; i++)` → 执行 n 次，最后一次 i = n−1，结束后 i = n。

### 4.5 二重循环

```c
for (i = 0; i < n; i++) {          /* 外层：行 */
    for (j = 0; j < m; j++) {      /* 内层：列 */
        ...
    }
    printf("\n");                  /* 换行：放在内层外面、外层里面 */
}
```

**三条规律**：
- 内层管"一行里有什么"，外层管"一行结束后做什么"。
- **找"任意两数"时 `j` 从 `i+1` 起**，避免自比和重复比较。
- 总执行次数 = 外层次数 × 内层次数。

### 4.6 三个经典模板

```c
/* ① 累加 / 计数 */
s = 0; for (i = 1; i <= n; i++) s += i;

/* ② 求最值（初值取第一个元素，绝不取 0） */
int mx = a[0];  for (i = 1; i < n; i++) if (a[i] > mx) mx = a[i];

/* ③ 拆位 */
s = 0; t = n; while (t > 0) { s += t % 10; t /= 10; }
```

### 4.7 本节易错清单

- [ ] 循环体内忘写 `i++` → 死循环（OJ 判 TLE）
- [ ] `i <= n` 与 `i < n` 混淆 → 多算/少算一次
- [ ] 累加器没清零 → 结果累加了上一题的值
- [ ] `printf` 放错位置 → 每轮都打印 / 最终结果没打印
- [ ] 浮点循环变量用 `!=` 判断 → 可能永不相等

## 5. 一维数组（第 12 讲）

### 5.1 定义与初始化

```c
int a[10];                        /* 10 个元素，下标 0~9 */
int a[10] = {0};                  /* 全部清零（推荐，防垃圾值） */
int a[5] = {1, 2, 3};             /* 前 3 个赋值，其余为 0 */
int a[] = {1, 2, 3};              /* 长度由初始化决定 = 3 */
```

**长度必须是常量**：`int a[n]` 在 C89 是错的（C99 支持变长数组，但机房老编译器可能不支持，**开大一点定长数组**）。

### 5.2 下标与遍历

```c
for (i = 0; i < n; i++) scanf("%d", &a[i]);   /* 注意 & */
for (i = 0; i < n; i++) printf("%d ", a[i]);

for (i = n - 1; i >= 0; i--) ...              /* 逆序遍历 */
```

**越界不会报错**，只会读到别的变量的值（UB）——**这是数组题最容易"看起来对但结果错"的原因**。

### 5.3 五个必会模板

```c
/* ① 求和 / 平均 */
int s = 0; for (i = 0; i < n; i++) s += a[i];
double avg = (double)s / n;

/* ② 最值（初值取 a[0]） */
int mx = a[0], mn = a[0];
for (i = 1; i < n; i++) { if (a[i] > mx) mx = a[i]; if (a[i] < mn) mn = a[i]; }

/* ③ 桶计数（下标当键） */
int cnt[16] = {0};
for (i = 0; i < n; i++) { scanf("%d", &x); cnt[x]++; }
for (i = 0; i < 16; i++) if (cnt[i] > 0) printf("%d %d\n", i, cnt[i]);

/* ④ 双指针（回文 / 反转） */
i = 0; j = n - 1;
while (i < j) { if (a[i] != a[j]) break; i++; j--; }

/* ⑤ 排序后取中位数 / 找相邻差 */
/* 简单冒泡： */
for (i = 0; i < n-1; i++)
    for (j = 0; j < n-1-i; j++)
        if (a[j] > a[j+1]) { t = a[j]; a[j] = a[j+1]; a[j+1] = t; }
```

### 5.4 什么时候需要数组

> **处理过程中需要"回头再看一遍"数据吗？**
> 需要 → 用数组；不需要 → 边读边算（省内存，也少出错）。

- 不用数组：求和、计数、最值、相邻比较、分段。
- 必须数组：找最小差值、选号、统计次数、逆序输出、排序、双指针。

### 5.5 本节易错清单

- [ ] 数组忘初始化 `= {0}` → 垃圾值
- [ ] `i <= n` → 越界
- [ ] `scanf("%d", a[i])` 漏 `&`
- [ ] 数组开 `a[n]` → 编译错
- [ ] 输出最后一个元素后多打空格

## 6. 字符数组 / 字符串（第 12 讲末，可能考）

```c
char s[55] = {0};        /* 必须初始化！否则读入失败时是垃圾 */
scanf("%s", s);          /* 不加 & */
while (s[i] != '\0') { ... i++; }   /* 遍历到结束符 */
```

- 字符串 = `char` 数组 + 末尾 `'\0'`。
- **`scanf("%s")` 读不了空格**，也读不了空串；**空输入时 `s` 保持未初始化状态**（这是"空密码 0 分"那个测试点的坑）。

## 7. 函数（第 13 讲，若在范围内）

```c
int Max(int x, int y) {          /* 形参是副本 */
    if (x > y) return x;
    else return y;
}
```

四条规则：
1. **函数只做一件事**：比较函数里不要 `scanf`/`printf`。
2. **值传递**：改形参不影响实参。
3. **数组作参数**传的是地址，函数内改数组会影响外部。
4. **深层嵌套先拆变量**：`Max(Max(a,b),Max(c,d))` 前先把 `a,b,c,d` 算成变量。
