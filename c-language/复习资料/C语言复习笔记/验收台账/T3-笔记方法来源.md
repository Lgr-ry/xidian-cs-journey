## 三　落成到本套笔记的 8 条可执行做法

1. 每章固定骨架：重点速览 → 正文 → 易错清单 → 源页对照 → 自测三题。
2. 每个知识点一句话定义 + 生活类比 + 最小可运行代码。
3. 三级重点标记：★★★ 红标 + 浅红底纹；★★ 橙标；★ 灰标。
4. 代码块行内注释直接点出易错处。
5. 每章 5–9 条"可判定的具体错误"，不写空话。
6. 每章 3 道自测题并给答案。
7. 知识点与源课件页码建立映射，可回查。
8. 源文件（HTML）与制品（PDF）分离，便于版本化与重建。
