# T6 统一笔记框架与章节模板

## 一　章节固定骨架（8 章一致）

```
h1  章标题 + 副标题（源课件 + 页数）
──  章首色带
chips  本章关键词
〇  本章导读（三列表：知识块 / 必须掌握 / 常见出错）
一~五  正文分节（每节：概念 → 表格或图 → 代码 → 易错提醒）
六  本章易错易混清单（7–9 条）
附  源课件页码对照（知识点 → 源文件第 N 页）
附  自测三题（问题 + 答案，蓝色框）
foot  源课件说明
```

## 二　每个知识点的写法（四段式）

1. **是什么**：一句话定义，尽量不带术语堆叠。
2. **怎么记**：表格对照或示意图（只在必要时）。
3. **怎么写**：可直接编译的最小代码，关键行带中文注释。
4. **错在哪**：`易错提醒` 框，列 2–4 条具体错误写法。

## 三　写作检查清单（用于 T14 验收）

- [ ] 每章有导读表，三列齐全
- [ ] 每章 ≥1 张表、≥1 段代码、≥1 个易错框
- [ ] 易错清单 ≥7 条，且每条是「可判定的具体错误」而非空话
- [ ] 每章有源页码对照表
- [ ] 每章有自测三题并给出答案
- [ ] 代码断言均可编译验证（见 T14 的代码核对项）
- [ ] 术语全书一致（如统一用「实参/形参」「退化为指针」）
