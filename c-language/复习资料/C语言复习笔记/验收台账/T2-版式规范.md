# T2 版式规范 v2（实现值）

在 v1 基础上新增「三级重点标记」与「重点速览表」两套组件；其余取值沿用 v1。

## 一　字体映射（沿用 v1）

| 用途 | 字体 | 取值 |
|---|---|---|
| 正文 | SimSun 宋体 | 10.5pt / 行距 1.72 |
| 章标题 | STZhongsong 华文中宋 | 21pt / #12306b |
| 节标题 | STZhongsong | 13.5pt / 左侧 4pt 竖条 |
| 表格、图注、清单、提示框、重点徽标 | KaiTi 楷体 | 8.4–10pt |
| 代码 | Consolas | 8.9pt |

## 二　新增：三级重点标记

| 等级 | 视觉 | 用途 |
|---|---|---|
| ★★★ | 红色徽标 `#d64545` + 白字；关键句用 `.core` 浅红底纹 `#fff5f4` + 左 3pt 红条 | 必须掌握：会直接决定题目对错 |
| ★★ | 橙色徽标 `#e8a33d` + 白字 | 需要理解：影响写法与选择 |
| ★ | 灰色 `#4b5563` 加粗，无徽标 | 知道即可：规范性与边缘知识 |

灰度打印检查：三种徽标除颜色外还有**文字（★★★/★★）与形状**差异，复印或黑白打印仍可区分。

## 三　新增：本章重点速览表

- 位置：每章「〇 本章导读」之后、正文之前。
- 结构：三列 `等级 / 知识点 / 为什么是重点·怎么考`。
- 表头底色 `#fdeceb`，等级列居中并用楷体。
- 作用：让读者 10 秒内知道本章哪几条必须拿下。

## 四　沿用 v1 的组件

章首色带、知识块 chip、三点式导读表、代码块（灰底 + 左蓝条）、橙色「方法要点」、灰色「易错提醒」、蓝色「本章小结 / 自测」、页眉页脚。

## 五　重点占比（可复算）

统计口径：正文 h2 小节（剔除固定的「速览 / 源页对照 / 自测」三个附加标题）为分母；带 badge3 或 badge2 的为分子。

```
★★★ 21 条　★★ 21 条　正文小节 60 个
重点（★★★）占比 = 21 / 60 = 35%   ← 落在 30%–40% 目标区间
次重点（★★）+ 一般（无标记）＝ 65%
```

复算方式：统计各章 HTML 中 `class="badge3"` / `class="badge2"` 出现次数，除以 `<h2>` 数减 24。
