## 二、逐条详解

### E01 `=` 与 `==` 混用（高频）

**现象**：条件恒真或恒假，输出爆炸式错误。
**根因**：`if (arr[v] = c)` 是「先赋值，再拿 c 当条件」，不是比较。
**正确**：

```c
if (arr[v] == c) { ... }
```

**实例**：T167 写成 `=`，样例本应 5 行，实际打印 12012 行。
**自查**：gcc 会警告 `suggest parentheses around assignment used as truth value`，看到就读一遍。
**模板**：`if (变量 运算符 变量)`，中间必须是两个字符。

---

### E02 变量与数组未初始化（高频）

**现象**：结果随机、第一次对第二次错。
**根因**：局部变量、局部数组是**垃圾值**，不是 0。
**正确**：

```c
int sum = 0;
int cnt[16] = {0};      /* 必须写 {0} */
int mx = a[0];          /* 最值取第一个元素，不取 0 */
```

**实例**：T41（`sum` 未初始化）、T75（`cnt` 未初始化）。
**自查**：看到 `int x;` 就问「它第一次被读之前赋值了吗」。

---

### E03 scanf 漏 `&` 或类型不匹配（高频）

**现象**：崩溃、断言失败、读入垃圾值。
**正确**：

```c
scanf("%d", &n);        /* int 要 & */
scanf("%lf", &x);       /* double 用 %lf */
scanf("%s", s);         /* 字符数组不加 & */
```

**自查**：`&` 的个数 = 格式符个数 = 变量个数（`%s` 除外）。

---

### E04 格式串与输入不匹配（中频）

**现象**：样例能过，一提交就错；或读入中断。
**根因**：`scanf` 里的普通字符（逗号、冒号）**不会跳过空格**。
**正确**：

```c
scanf("%d,%c", &a, &b);     /* 输入必须严格是 3,5 */
scanf("%d ,%c", &a, &b);    /* 逗号前加空格 = 容忍空白 */
```

**实例**：T18 题面输入 `3 ,5`，原写法失配。
**自查**：把「输入说明」里的标点原样抄进格式串。

---

### E05 输出格式不符（高频）

**现象**：逻辑全对，判题 WA。
**四类**：
1. 大小写：题面 `No`，写成 `no`。
2. 多余空格：`printf("%d ", a[i])` 最后一项多一个空格。
3. 多余提示语：`printf("请输入:")` 交 OJ 必错。
4. 缺换行：多行输出没有 `\n`，全挤成一行。

**正确模板**：

```c
/* 输出 n 个数，空格分隔，最后换行 */
for (i = 0; i < n; i++) {
    if (i) printf(" ");
    printf("%d", a[i]);
}
printf("\n");
```

**自查**：把程序输出和样例**并排贴在一起**逐字符看。

---

### E06 整数除法截断（中频）

**现象**：平均值、体积、比例全是整数或 0。
**正确**：

```c
double c = (F - 32) * 5.0 / 9.0;
double avg = (double)sum / n;
```

**自查**：看到除号，先确认两边有没有浮点数。

---

### E07 循环边界错（高频）

**现象**：多算一次、少算一次、越界。
**三种典型**：
- `for (i = 0; i <= n; i++)` → 越界，应 `< n`
- 校验循环里访问 `a[i+1]`，上界应 `i < n-1`
- 循环结束后又用 `i`，但它已经多加了 1

**正确**：写完回答三问——**跑几次？最后一次 i 是几？结束后 i 是几？**
**自查**：代 `n = 1` 和 `n = 3` 各手推一遍。

---

### E08 循环不推进或内外层同变量（高频）

**现象**：程序卡死（TLE）、只跑一遍。
**正确**：

```c
while (n != 1) { n = n / 2; }       /* 体内必须改 n */

for (i = 0; i < n; i++)             /* 内外层用不同变量 */
    for (j = 0; j < m; j++) ...
```

**自查**：每个 `while` 问一句「哪个语句让条件最终变假」。

---

### E09 冒泡排序写错（高频）

**现象**：有序输入能过，乱序就错。
**三种错法**：内层 `j < i`（扫不到尾）、内层用 `i` 比较（重复同一对）、`i <= n`（越界）。
**正确模板**：

```c
for (i = 0; i < n - 1; i++)
    for (j = 0; j < n - 1 - i; j++)
        if (a[j] > a[j+1]) {
            int t = a[j]; a[j] = a[j+1]; a[j+1] = t;
        }
```

**自查**：用「乱序 5 个数」测，不要用样例（样例常是有序的）。

---

### E10 数组越界（中频）

**现象**：结果错但不报错（未定义行为）。
**正确**：数组开 `1005` 不写 `1000`；访问上界 `n-1`；用 `a[i+1]` 时 `i < n-1`。
**自查**：把所有下标上界抄一遍，逐个核对是 `n` 还是 `n-1`。

---

### E11 赋值给错变量（中频）

**现象**：某个分支结果恒为 0 或初始值。
**实例**：T374 `else if (t > 50) { t = 20; }`——把温度赋给了输入变量 `t`，输出变量 `c` 仍是 0。
**对策**：**输入与输出变量分开命名**（`n / a / b` 对 `ans / result`）。
**自查**：每个分支写完，看末尾赋值的变量是不是要输出的那个。

---

### E12 结构不完整（中频）

**现象**：编译错误（CE）。
**三类**：缺右花括号；声明缺类型（`long i=0; x; n=0;`）；把 `<=` 敲成 `<+`。
**自查**：
1. 每写一个 `{` 立刻补 `}`（先括号后内容）。
2. 每 15 行编译一次。
3. **读编译警告**——warning 常常就是 bug 的位置。

## 三、六个必背模板

```c
/* ① 拆位 */
s = 0; t = n; while (t > 0) { s += t % 10; t /= 10; }

/* ② 最值 + 位置 */
mx = a[0]; pos = 0;
for (i = 1; i < n; i++) if (a[i] > mx) { mx = a[i]; pos = i; }

/* ③ 桶计数 */
int cnt[1005] = {0};
for (i = 0; i < n; i++) { scanf("%d", &x); cnt[x]++; }

/* ④ 双指针（回文 / 反转） */
i = 0; j = n - 1;
while (i < j) { if (a[i] != a[j]) { ok = 0; break; } i++; j--; }

/* ⑤ 冒泡排序 */
for (i = 0; i < n - 1; i++)
    for (j = 0; j < n - 1 - i; j++)
        if (a[j] > a[j+1]) { int t = a[j]; a[j] = a[j+1]; a[j+1] = t; }

/* ⑥ 分段累进（档宽 × 本档税率） */
if (I <= 100000)      ans = I * 0.1;
else if (I <= 200000) ans = 10000 + (I - 100000) * 0.075;
```
